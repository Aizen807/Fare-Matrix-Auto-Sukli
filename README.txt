## How to Capture

1. Open Roblox in Windowed Mode
2. Press F3 in the AHK script to resize to your resolution
3. Use Windows Snipping Tool
4. Crop tightly around each element
5. Save as PNG with the exact filenames above

## Tips

- Smaller images = faster detection
- PNG format is required
- Use the same resolution every time (press F3 before capturing)
- If detection fails, recapture the image with better contrast

## Optional Images (For Better Reliability)
